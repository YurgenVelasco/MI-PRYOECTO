## 📖 Acerca del proyecto

**MI-PRYOECTO** es un proyecto académico desarrollado como parte de mi aprendizaje de los fundamentos de HTML y la construcción de páginas web.

A través de ejercicios prácticos, exploro la estructura de los documentos HTML, las etiquetas de formato, la organización de contenido y la representación de información mediante listas, tablas y otros elementos.

El propósito principal es **comprender cómo funciona una página web desde sus bases**, antes de incorporar estilos avanzados, interactividad y tecnologías más complejas.

> 💡 **Filosofía del proyecto:** Antes de construir grandes aplicaciones, es importante comprender los fundamentos que hacen posible su funcionamiento.

## 🎯 Objetivos de aprendizaje

Este proyecto busca fortalecer las siguientes competencias:

## ✨ ¿Qué contiene el proyecto?

El repositorio reúne diferentes ejercicios que permiten explorar las características fundamentales de HTML.

### 📝 1. Encabezados y estructura de contenido

Utilización de etiquetas para definir jerarquías de información.

```html
<h1>Título principal</h1>
<h2>Sección secundaria</h2>
<h3>Subsección</h3>

<p>Este es un párrafo de ejemplo.</p>
```

**Conceptos practicados:**

- Jerarquía de encabezados.
- Organización de párrafos.
- Saltos de línea.
- Separadores temáticos.

### 🎨 2. Formato y semántica de texto

Implementación de etiquetas que aportan significado y estructura al contenido.

| Etiqueta | Función |
|:---:|---|
| `<strong>` | Representar texto de especial importancia |
| `<em>` | Aplicar énfasis |
| `<mark>` | Resaltar contenido relevante |
| `<small>` | Representar anotaciones o texto secundario |
| `<sub>` | Crear subíndices |
| `<sup>` | Crear superíndices |
| `<br>` | Insertar un salto de línea |
| `<hr>` | Crear un separador temático |

Estas prácticas permiten comprender que HTML no solamente muestra contenido: también proporciona significado a los elementos de una página.

### 📋 3. Listas y organización de información

El proyecto incluye tres tipos fundamentales de listas.

**Listas desordenadas:**

```html
<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>
```

**Listas ordenadas:**

```html
<ol>
  <li>Planificar</li>
  <li>Diseñar</li>
  <li>Desarrollar</li>
</ol>
```

**Listas descriptivas:**

Se exploran las etiquetas `<dl>`, `<dt>` y `<dd>` para relacionar términos con sus respectivas descripciones.

### 📊 4. Tablas HTML

Práctica de organización de datos mediante estructuras tabulares.

```html
<table>
  <tr>
    <th>Hora</th>
    <th>Actividad</th>
  </tr>
  <tr>
    <td>7:00</td>
    <td>HTML</td>
  </tr>
  <tr>
    <td>9:00</td>
    <td>CSS</td>
  </tr>
</table>
```

**Etiquetas utilizadas:**

- `<table>`: estructura general.
- `<tr>`: filas.
- `<th>`: celdas de encabezado.
- `<td>`: celdas de datos.

### 💬 5. Citas y fragmentos de código

Se trabaja con elementos que permiten representar información especializada.

- `<blockquote>`: citas en bloque.
- `<code>`: fragmentos de código.
- `<pre>`: contenido preformateado.

Ejemplo:

```html
<blockquote>
  La mejor manera de aprender es haciendo.
</blockquote>
```

## 🚀 Instalación y ejecución

El proyecto no requiere procesos de compilación ni instalación de dependencias.

### Requisitos

- Un navegador web moderno.
- Git, únicamente si desea clonar el repositorio.
- Un editor de código, opcional.

### Paso 1 — Clonar el repositorio

Abra una terminal y ejecute:

```bash
git clone https://github.com/YurgenVelasco/MI-PRYOECTO.git
```

### Paso 2 — Acceder al directorio

```bash
cd MI-PRYOECTO
```

### Paso 3 — Ejecutar

Abra el archivo `index.html` en su navegador.

También puede utilizar Visual Studio Code junto con una extensión como Live Server.

**No necesita configurar variables de entorno, servicios ni bases de datos.**
