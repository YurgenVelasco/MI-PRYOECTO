## 📖 Descripción

**MI-PRYOECTO** es un proyecto académico desarrollado para aprender y practicar los fundamentos de **HTML5** y la construcción de páginas web.

Su objetivo es comprender cómo se estructura un documento HTML, cómo funcionan sus principales etiquetas y cómo organizar contenido mediante encabezados, párrafos, listas, tablas y otros elementos.

Este repositorio forma parte de mi proceso de formación como desarrollador de software.

---

## 🎯 Objetivos de aprendizaje

- Comprender la estructura básica de un documento HTML.
- Utilizar encabezados para organizar contenido.
- Crear párrafos y aplicar formatos de texto.
- Construir listas ordenadas, desordenadas y descriptivas.
- Representar información mediante tablas.
- Trabajar con etiquetas para citas y fragmentos de código.
- Familiarizarme con el desarrollo de páginas web.
- Practicar el control de versiones con Git y GitHub.

## ✨ Contenido del proyecto

### 📝 Encabezados y párrafos

Práctica de etiquetas para estructurar el contenido:

- `<h1>`, `<h2>` y `<h3>` para encabezados.
- `<p>` para párrafos.
- `<br>` para saltos de línea.
- `<hr>` para separadores temáticos.

### 🎨 Formato de texto

Ejemplos de etiquetas HTML:

| Etiqueta | Función |
|---|---|
| `<strong>` | Indicar importancia en el texto |
| `<em>` | Aplicar énfasis |
| `<mark>` | Resaltar contenido |
| `<small>` | Representar texto secundario |
| `<sub>` | Crear subíndices |
| `<sup>` | Crear superíndices |

### 📋 Listas HTML

El proyecto incluye tres tipos de listas:

- **`<ul>`:** listas desordenadas.
- **`<ol>`:** listas ordenadas.
- **`<dl>`:** listas descriptivas que utilizan `<dt>` y `<dd>`.

### 📊 Tablas

Se utilizan etiquetas como:

- `<table>` para definir una tabla.
- `<tr>` para crear filas.
- `<th>` para definir celdas de encabezado.
- `<td>` para representar los datos.

La práctica incluye una tabla sencilla con horarios y actividades relacionadas con HTML y CSS.

### 💬 Citas y fragmentos de código

También se exploran las etiquetas:

- `<blockquote>` para citas en bloque.
- `<code>` para fragmentos de código.
- `<pre>` para mostrar contenido preformateado.

## 🚀 Cómo ejecutar el proyecto

No es necesario instalar dependencias ni configurar un servidor.

### 1. Clonar el repositorio

```bash
git clone https://github.com/YurgenVelasco/MI-PRYOECTO.git
```

### 2. Entrar al directorio

```bash
cd MI-PRYOECTO
```

### 3. Abrir la página

Abra el archivo `index.html` en su navegador preferido.

También puede utilizar Visual Studio Code y una extensión de servidor local, aunque no es obligatorio.
